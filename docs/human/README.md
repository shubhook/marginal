# Marginal

Marginal is a personal notebook app that combines a freeform infinite canvas, direct PDF markup, and notes tied to specific PDF pages, all in one place, running entirely in your browser. It's built for one person's daily use — coursework notes, project sketches, marking up PDF readings — not as a product for other users.

## What you can do today

- **Notebooks** — group related boards and PDFs together instead of one flat pile of everything.
- **Boards** — an infinite canvas for freehand notes, shapes, and text.
- **PDF markup** — import a PDF and draw directly on the page.
- **Named canvas layers** — attach multiple independent, named note-canvases to any PDF page, for notes that don't fit in the margin, without cluttering the page itself.
- **Export** — save a board or a PDF page (with its markup) as PNG, SVG, or PDF.
- **Search** — jump to any notebook, board, or PDF by name.
- **Trash** — deleted notebooks, boards, and PDFs go to Trash first, not gone for good.

## Tech stack, one line

Next.js + tldraw + Dexie/IndexedDB, no backend, runs entirely in the browser.
